# ClassPlay

ClassPlay is a static, English-language portal of free browser games screened
for school: math, puzzle and brain games first, plus gentle skill games and
friendly sports. Every game loads in a normal browser tab — no downloads, no
installs, no sign-ups — and works on Chromebooks, laptops and phones.

**Live site:** https://classplay.online/

Built with [Astro](https://astro.build) (fully static output), deployed to
GitHub Pages by GitHub Actions on every push to `main`.

## How ClassPlay differs from its sister site TabArcade

ClassPlay shares a codebase lineage with TabArcade (same build system, same
licensed feeds, same card/hero design components) but it is **not a mirror**:

| | TabArcade | ClassPlay |
|---|---|---|
| Positioning | General "unblocked games" arcade | Classroom-screened games for school |
| Audience voice | Students | Students **and** teachers/parents |
| Theme | Dark neon arcade | Light, bright, friendly (sky/mint/sun) |
| Catalog | 149 games incl. shooters & battle | **80-game subset**: no Shooter category, no zombie/horror/scary/ghost-tagged titles, no fighting/battle games, no gun/weapon tags |
| Home order | Driving/running led | **Math, puzzle and brain games lead**; featured = top thinking games |
| Hubs | 10 hubs (driving, running, .io…) | 8 own hubs: classroom, math, puzzle-for-school, brain, sports, Chromebook, school breaks, 2-player classroom |
| Copy | TabArcade originals | All home/hub/about copy written fresh for ClassPlay |

## How the game catalog is generated

Games come from licensed syndication feeds — never scraped or ripped:

- **GameDistribution:** catalog API → `src/data/games.json`
- **GameMonetize:** feed (`gamemonetize.com/feed.php`) → `src/data/games-gm.json`

Regenerate in three steps (order matters):

```bash
npm run fetch-games        # GD full catalog  -> games.json
npm run fetch-gm           # GM full catalog  -> games-gm.json
node scripts/filter-catalog.mjs   # classroom subset + ClassPlay URLs/branding
```

No API keys are needed — both feeds are public. `scripts/filter-catalog.mjs`
is the ClassPlay differentiator: it applies the classroom-safe exclusion
rules, selects ~80 games with per-family caps (brain/puzzle 34, sports 12,
agility 14, .io 10, racing 9), orders educational-leaning games first, flags
the top 12 as `featured`, rewrites `pageUrl` and the GD embed referrer to
`https://classplay.online`, and re-brands descriptions to ClassPlay.

`src/lib/games.mjs` is the merged catalog accessor every page reads from:
GD games keep their order, GM games are interleaved (1 after every 4 GD
games), duplicates lose to GD.

### Revenue attribution

- **GameDistribution:** embed URLs carry
  `?gd_sdk_referrer_url=<this game's ClassPlay page URL>` (rewritten by the
  filter script). Revenue is credited to the publisher account that has
  **classplay.online** registered — register the domain in a GD publisher
  account before promoting the site.
- **GameMonetize:** attribution is **domain-based** (no ID in the embed).
  classplay.online must be submitted in the GM publisher dashboard and its
  ads.txt verified before plays earn. (Not yet submitted — that happens
  after DNS/HTTPS are live.)

## Adding or removing games

1. Refresh the data (the three commands above), **or** hand-edit the JSON
   files — then re-run `node scripts/filter-catalog.mjs` so subset rules,
   ordering and URLs stay consistent.
2. `npm run build` — game pages, grids, related rails and the sitemap are
   all generated from the data files.
3. Push to `main` — GitHub Actions rebuilds and redeploys automatically.

To change the featured games, adjust the selection in
`scripts/filter-catalog.mjs` (featured = top 12 of the ranked selection).

## Site structure

| Path | What |
|---|---|
| `src/pages/index.astro` | Home: hero, featured grid, math/puzzle/brain-led sections, "Why ClassPlay?" |
| `src/pages/games/[slug].astro` | One page per game: playable iframe + fullscreen button, About, How to Play, FAQ (incl. a classroom-appropriateness Q), related games, VideoGame + FAQPage + Breadcrumb JSON-LD |
| `src/pages/[hub].astro` | The 8 ClassPlay hub pages (copy in `src/data/hubs.mjs`) |
| `src/lib/games.mjs` | Merged catalog accessor, shelves, related-games scoring, FAQ generator, URL helper |
| `src/lib/art.mjs` | Pop-out key art registry + per-category accent colors (light-theme set) |
| `src/layouts/Base.astro` | Shared layout: meta/canonical/OG, nav, global styles (light theme) |
| `public/robots.txt` | Points crawlers at the sitemap |
| Sitemap | Auto-generated by `@astrojs/sitemap` at `/sitemap-index.xml` |

Positioning rule: always phrase the site as "free classroom games — no
downloads, Chromebook-friendly". Never use "bypass school filters" framing,
and never add a game the classroom screen would reject.

## Local development

```bash
npm install
npm run dev        # local dev server
npm run build      # static build into dist/
npm run preview    # preview the built site
```

## Deploy flow

Push to `main` → `.github/workflows/deploy.yml` runs the official Astro
GitHub Action (build) → `actions/deploy-pages` publishes to GitHub Pages.
The site serves from the custom domain **https://classplay.online** (root):
`astro.config.mjs` sets `site: 'https://classplay.online'` and `base: '/'`,
`public/CNAME` carries the domain, and the Pages API has the same cname set.
The project URL `https://honru09.github.io/classplay/` redirects to the
custom domain once DNS is in place.
